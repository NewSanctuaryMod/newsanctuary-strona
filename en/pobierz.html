What you need

  • Diablo II: Resurrected with the Reign of the Warlock expansion (your own, purchased copy of the game).
  • D2RLoader – the program that loads the mod into the game. It is made by another modder, so you download it from their page.
  • NewSanctuary – the mod, for single player and TCP/IP multiplayer (no Battle.net).

Download

1. D2RLoader

On the author’s page open the “Files” tab and download version 1.3.1 – newer versions may not work with the mod.

Installation

  1. Download D2RLoader v1.3.1 and New Sanctuary v1.5.0.
  2. Extract D2RLoader v1.3.1 into the game folder (the whole contents of its archive).
  3. Extract New Sanctuary v1.5.0 into the game folder – the archive contains only the “mods” folder. When Windows asks about existing files, choose “Replace”.
  4. Start the game with the loader icon, click the gear button below “Play” in the menu, on the General tab set Default mod to InvGrid5 (that’s New Sanctuary’s name on the mod list), click “Apply” and restart the game. Done – from now on the loader starts the mod by itself.

The mod adds new items. Do not remove it while a character has them in the inventory or stash, or the save may fail to load.

Updating from version 1.4.0 or older: step 3 is enough (the mod is already selected in the loader). You can delete the old d2rl-*.dll files from the d2rloader\plugins folder in the game folder – the mod now uses its own.
