What you need

  • Diablo II: Resurrected with the Reign of the Warlock expansion (your own, purchased copy of the game).
  • D2RLoader – the program that loads the mod into the game. It is made by another modder, so you download it from their page.
  • NewSanctuary – the mod, for single player and TCP/IP multiplayer (no Battle.net).

Installation

  1. Download the loader and the mod, then extract each one into a separate folder.
  2. Copy the contents of the extracted mod (both folders) into the loader folder. When Windows asks about existing files, choose “Replace”.
  3. Copy the whole contents of the loader folder (2 folders and 3 files) into the game folder.
  4. Done – start the game with the loader icon.

The mod adds new items. Do not remove it while a character has them in the inventory or stash, or the save may fail to load.
