What you need

  • Diablo II: Resurrected with the Reign of the Warlock expansion (your own, purchased copy of the game).
  • D2RLoader – the program that loads the mod into the game. It is made by another modder, so you download it from their page.
  • NewSanctuary – the mod, for single player and TCP/IP multiplayer (no Battle.net).

On the author’s page open the “Files” tab and download version 1.3.1 – newer versions may not work with the mod.

Installation

  1. Download D2RLoader v1.3.1 and New Sanctuary v2.1.0.
  2. Extract D2RLoader v1.3.1 into the game folder – the whole contents of the archive: 2 folders (d2rloader, mods) and 3 files (D2RCore.dll, D2RLoader.exe, d2rloader.mpq).
  3. Extract New Sanctuary v2.1.0 into the game folder – the archive contains only the mods folder. Replace existing files if Windows asks.
  4. Set the mod in D2RLoader:
    1. start the game with D2RLoader (if a “This D2R version hasn’t been fully tested yet” window appears, tick “Don’t remind me again for D2R 3.4” and click OK – the mod works fine),
    2. click the gear icon below the Play button,
    3. on the General tab set Default mod to New Sanctuary,
    4. click Apply – the game restarts by itself, already with the New Sanctuary mod.

Done! From now on the game starts with the New Sanctuary mod.

The mod adds new items. Do not remove it while a character has them in the inventory or stash, or the save may fail to load.

D2RLoader settings: two options in the Gameplay tab (Vanilla section) have no effect in the mod – the mod controls them itself. Generate new map layouts – the mod always rolls a new map layout on every character load and clears the old automap. Offline Difficulty Scaling – the player count (P1–P8) is disabled, the /players command and this slider do nothing; a higher P level comes only from playing together with real players over TCP/IP.

Updating from version 2.0.0: do step 3 (replace files) – nothing else is needed.

Updating from version 1.6.0: do step 3 (replace files) and delete the file d2rl-krowy-bez-wytrzymalosci.dll from mods\New Sanctuary\d2rloader\plugins – nothing else is needed.

Updating from version 1.5.0 or older: do step 3, delete the old mods\InvGrid5 folder (from 1.4.0 or older also the old d2rl-*.dll files in d2rloader\plugins) and do step 4. The first time you select each old character, a warning about a different mod appears next to Play – that’s normal, the character loads fine.
