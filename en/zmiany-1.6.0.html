Changes in version 1.6.0

Download Mod

Version 1.6.0 from 16.11.2026. The mod folder has a new name – see below how to update. Character saves and charms in the pouch stay. Changes in the previous version: 1.5.0.

New mod name

  • The mod folder is now called mods\New Sanctuary (before: mods\InvGrid5), and the “Default mod” list in the D2RLoader settings shows “New Sanctuary”.
  • Updating: extract the archive into the game folder, delete the old mods\InvGrid5 folder and in the loader settings (gear button below “Play” → General → Default mod) select New Sanctuary and click “Apply” – the game restarts by itself, already with the mod.
  • Character saves stay where they were. The first time you select each old character, a warning about a different mod appears next to “Play” – that’s normal, the character loads fine and the warning disappears.

Camera

  • New hint for a new character: “Press the zoom key and set the camera with the mouse wheel”. You set a comfortable view once – the game remembers it separately for each character.

Menu

  • New artwork for the left panel of the main menu.
