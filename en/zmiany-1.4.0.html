Changes in version 1.4.0

Download Mod

Version 1.4.0 from 15.11.2026. Install it like the previous versions (contents of the zip into the game folder, replacing files). Character saves stay. Changes in the previous version: 1.3.0.

Camera

  • Terrain is drawn one room further than in the normal game. At a far zoom no black patches of the map appear in the screen corners any more (before, they sometimes showed up at the farthest view).
  • Monsters and gameplay are unchanged – only terrain drawing changes.
  • On a weaker computer, if the game gets less smooth at the farthest view: don’t zoom out all the way, or in d2rl-plynne-przyblizenie.txt (d2rloader\plugins folder) set co_klatek=3 (if the game stutters when moving between rooms) or dalej=0. You can also set 17 views: kroki=16 and najdalej=0.974.

Item labels on the ground

  • When many items lie on the ground, the game tries to place each label up to 48 times (16 in the normal game) before hiding it. Far fewer labels disappear, e.g. after killing a boss.
  • The number of tries can be changed in d2rl-napisy-na-ziemi.txt (d2rloader\plugins folder, proby=16–127).

Skills

  • A new hint under the skill selection panel: “You can bind up to 16 skills to keys of your choice” (before, the game showed only the first and the eighth key, while there are 16 keys) and “All skills available on LMB and RMB”.

Tool descriptions

  • Gray tool footers without “Result:”, as short sentences, e.g. Hatchet: “Experience grows again up to level 100”, File: “The item becomes ethereal”, Pliers: “Filled sockets become empty again and their contents are lost”.
  • The Hand Drill describes sockets for each item quality, and the Flat Chisel the tier change (normal → exceptional → elite).
