Changes in version 2.4.0

Download Mod

Version 2.4.0 from 19.11.2026. A new layout of the “Advanced Stats” window and the real weapon speed in the item description. Character saves and charms in the pouch stay. Updating from 2.3.5: extract the archive into the mods folder in the game folder and replace the files. Changes in the previous version: 2.3.5.

“Advanced Stats” window

  • The window is narrower, while the tiles are wider and start at the very top of the list – long lines no longer wrap.
  • Each tile is a header with one value per line, in a new block order. New “On hit” (crushing blow, deadly strike, open wounds, pierce, freeze, slow, knockback…) and “On kill” blocks.
  • Resistances: a new “Physical resistance: X / 50” line. Damage reduction: physical and magic points.
  • Thorns: physical and lightning, plus percentage damage return (melee and missiles). Regeneration: also “damage taken goes to mana”.
  • Attack speed: a new line “Weapon: name (type, weapon speed N)” – also for two weapons and the mercenary – followed by “Attack: N frames”.

Weapon description

  • Instead of “Axe Class – Normal Attack Speed” there is just “Axe Class”, with the real “Weapon speed: N” below it (every weapon).
