Changes in version 2.5.0

Download Mod

Version 2.5.0 from 19.11.2026. A new look for the “Advanced Stats” window, a separate set of lines for the mercenary, a simpler difficulty window and shorter texts in a few windows. Character saves and charms in the pouch stay. Updating from 2.4.0: extract the archive into the mods folder in the game folder and replace the files. Changes in the previous version: 2.4.0.

“Advanced Stats” window

  • A new window frame and background, with decorative horizontal bars between the blocks.
  • Player count block: the header on its own line, the values for 1–8 players below it.
  • Unreached breakpoints (cast, hit recovery, block, attack) are white instead of grey; the reached one is still orange.
  • Character: all tiles are shown, also those with a value of 0.
  • Mercenary: only the lines that apply to it – no cast and block rate, magic find, gold, weapon masteries, player count, kills or extra experience; no empty tiles.

Difficulty window

  • Only unlocked difficulty levels are shown, centred (e.g. Normal alone in the middle).
  • The window title is just “Difficulty”.

Menus and windows

  • Pause menu: “Exit” moved to the bottom (Return, Options, Filter, then Chronicle and Exit).
  • Exit window: just “Exit” instead of the question.
  • Deleting a character: “Hold to delete”.
