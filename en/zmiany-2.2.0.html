Changes in version 2.2.0

Download Mod

Version 2.2.0 from 18.11.2026. Level numbers in the skill trees, a new layout for some Sorceress and Warlock skills, a stun on Leap Attack, and Super and Uber Heralds. Character saves and charms in the pouch stay. Updating from 2.1.0: extract the archive into the game folder and replace the files. Changes in the previous version: 2.1.0.

Skill trees

  • Every row has a tile with the required character level: 1, 6, 12, 18, 24 and 30.
  • Tiles of levels your character has not reached yet are dimmed like unavailable skills.
  • The skill columns and tiles are evenly centred in the panel.

Barbarian

  • Leap Attack stuns the enemy it hits for 0.6 seconds.

Terror Zones

  • Heralds in zones after a Super Shard are called Super Heralds, and after an Uber Shard – Uber Heralds. The shard descriptions use the same names.

Menus and windows

  • A newly created character enters the game right away, without the difficulty window. The window works as before for existing characters.
  • The start screen shows the game name above the mod name.
