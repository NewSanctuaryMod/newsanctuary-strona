Changes in version 1.5.0

Download Mod

Version 1.5.0 from 16.11.2026. Installation changes – see below. Character saves and charms in the pouch stay. Changes in the previous version: 1.4.0.

Installation

  • The mod’s plugins and settings now live in its own folder (mods\InvGrid5\d2rloader). The archive contains only the mods folder and no longer overwrites your D2RLoader settings.
  • Updating from version 1.4.0 or older: extract the archive into the game folder, replacing files – that’s all. You can delete the old d2rl-*.dll files from the d2rloader\plugins folder (the ones in the mod folder take priority anyway).
  • New installation: select the mod once in the loader settings – gear button below “Play” → General → Default mod → InvGrid5 (New Sanctuary’s name on the list) → “Apply”, then restart the game (details on the Download page).

Camera

  • A new character starts fully zoomed in – for about 10 seconds a hint below the character says “Scroll the mouse wheel to zoom the camera out”.
  • Each time you scroll, “Camera: N %” briefly appears – 0 % is the closest view, 100 % the farthest.
  • The mouse wheel now has 20 even steps, exactly 5 % each.

Title screen and menus

  • The title screen corners show: D2RLoader with its version (top left), the mod name and version (top right), the game name with expansion and version number (bottom right) and the Blizzard logo (bottom left).
  • The loading screen, main menu and pause menu no longer show the animated game logo; the left panel of the main menu has an even background tone.

Fixes

  • The mod check recognizes the game version again and warns when the mod may not work after a game update.
  • The perfect gem and skull recipes (rerolling affixes) now have English descriptions too.
