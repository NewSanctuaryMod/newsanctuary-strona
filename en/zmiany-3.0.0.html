Changes in version 3.0.0

Download Mod

Version 3.0.0 from 22.11.2026. A new skill tree: 5 rows with arrows. Character saves and charms in the pouch stay. Updating from 2.8.0: extract the archive into the mods folder in the game folder and replace the files. Changes in the previous version: 2.8.0.

Skill tree

  • 5 rows instead of 6, unlocked at character levels 1, 8, 16, 24 and 32.
  • Arrows between rows in every column.
  • Skills from the old 6th row moved up.
  • Empty slots are lightly shaded instead of transparent.

Automap

  • The unopenable chest in the Countess's chamber has no marker. Opened chests, super chests too, still disappear.
