Changes in version 2.3.0

Download Mod

Version 2.3.0 from 18.11.2026. A new archive layout, fixes for character names with non-English letters, the mod logo on the start screen for 5 seconds and menu tidy-ups. Character saves and charms in the pouch stay. Updating from 2.2.0: extract the archive into the mods folder in the game folder and replace the files. Changes in the previous version: 2.2.0.

Installation

  • The archive now contains only the New Sanctuary folder (no mods folder). Extract or copy it into the mods folder that appears in the game folder after extracting D2RLoader.

Start screen

  • The mod logo stays for 5 seconds, then the game moves on by itself. A key press skips the wait.
  • When connecting to Battle.net takes longer, you see a dimmed screen and the “Connecting to Battle.net” box (without the animated game logo). Other waiting boxes, e.g. while saving, still do not cover the screen.
  • The top right corner shows only the mod name and version.

Menus

  • Pause menu: buttons in the order Exit, Return, Options, Filter, Chronicle. The “Save” button is now called “Exit” – as before it saves the character and leaves the game.
  • Main menu: the “D2RLoader” button is now called “Loader”.

Characters

  • Names with non-English letters (e.g. Polish Śnieżka) work with the camera, bottom bar buttons, kill counter and Halbu’s reward – long names too.
  • A new character created with the Enter key (instead of the Create button) also goes straight into Normal, without the difficulty window.
  • The camera hint for a new character stays on screen until you first change the camera.

Items

  • The Potion of Luck drops half as often.
